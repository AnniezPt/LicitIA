# Referencia visual de Stitch

Esta carpeta contiene una copia local de la exportación realizada el 30 de septiembre de 2026 desde el proyecto de Stitch `Pliego Claro Tender Workspace`.

La exportación se conserva como referencia y no sustituye al MVP funcional. La pantalla original de Stitch se dejó intacta. La copia incluye:

- `stitch-export-2026-09-30/stitch_pliego_claro_tender_workspace.zip`: exportación completa.
- pantallas HTML y capturas de `Hoy`, `Oportunidades`, `Expediente`, `Tareas` y `Ajustes`;
- `pliego_claro_design_system/DESIGN.md`: colores, tipografía, espaciado, componentes y estados GO / REVISAR / NO-GO.

## Criterio de integración

Se han trasladado al MVP las decisiones que aportan valor al flujo de prueba: navegación lateral, jerarquía de expediente, estados legibles, pestañas, trazabilidad, advertencias de datos de ejemplo y búsqueda local. No se han copiado afirmaciones de sincronización, hashes ni conexión oficial que no exista todavía en este MVP.
