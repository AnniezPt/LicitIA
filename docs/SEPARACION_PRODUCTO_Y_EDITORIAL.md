# Separación de Pliego Claro y Room 137

Esta separación es una decisión de producto, no solo de contenido.

## Pliego Claro

Aplicación privada para una empresa o un equipo pequeño.

Su trabajo es ayudar a:

- entender una oportunidad;
- identificar requisitos;
- asociar evidencias de la empresa;
- detectar carencias;
- decidir GO / REVISAR / NO-GO;
- crear la siguiente tarea.

La pantalla principal debe ser una superficie de trabajo, no una portada editorial.

## Room 137

Espacio editorial público.

Su trabajo es publicar noticias, contexto y análisis sobre licitaciones y otros temas.

Puede usar expedientes concretos como historias o artículos, pero esos expedientes no deben aparecer automáticamente dentro de Pliego Claro como si fueran contenido de la aplicación.

## Regla para no volver a mezclarlos

Un expediente real puede servir para probar Pliego Claro, pero dentro de la aplicación se presenta como **dato de trabajo del usuario**, no como noticia. Los ejemplos iniciales son neutros y editables. El usuario añadirá sus propios expedientes durante las pruebas.

No se comparte navegación, identidad visual editorial, tarjetas de noticias ni contenido de Room 137 en el MVP de Pliego Claro.
